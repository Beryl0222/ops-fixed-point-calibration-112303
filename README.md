# 流式有符号直方图校准与截幅证明

`data/record.json` 是 流式有符号直方图校准与截幅证明 使用的本地合成交换样本。数组按 JSON 的下标顺序排列。本文的坐标、单位和枚举约定与该记录配套。记录中如果有 `scale` 或 `limits`，对应同一输入协议的部署规格。

bins 的端点都包含，第三列为整段总质量，段内每个整数点质量相等。相邻段或来源片重叠时，代表不同统计贡献。通道 a、b 共享输入尺度和零点，闭区间 q_range 是有符号输入码范围。先对 x/scale 做有理数最近偶数舍入再加零点，超出输入码范围才算截幅。weights 内各行为一输出单元的权重码，偏置码以乘积累加单位表示。input_envelopes 给出部署承诺的各输入分量物理闭区间，候选须按实际舍入和截幅取得设备可达整数范围。这些区间中的分量可独立变化。给定部署配置时，越过所证明物理域的张量应拒绝。输出单位等于输入 scale，组合输出为两路整数点积之和加偏置，乘积使用去零点码，结果码为同一值加共享零点。每路部分和、合并累加及输出码均按有符号位宽验证，部分和要求任意求和次序均合法。误差相等时按升序尺度、再升序零点选择。

## 读取样本

使用 Python 3.11 或 3.12，并在虚拟环境安装锁定依赖。读取入口返回原始记录。作为命令运行时，它会列出各顶层输入项目以及 NumPy 版本。

```sh
python -m pip install -r requirements.txt
python -m fixed_point_calibration_input
python -m unittest discover -s tests -v
```

测试读取交换样本，核对其中的张量尺寸、标识与数据约定。
